# EEG evaluation audit

Analysis code for *"Random data splitting inflates EEG classification accuracy: evidence from recording fingerprints, cross-subject evaluation and external validation"* (Cho & Kim).

The pipeline evaluates the same EEG classification task under three evaluation schemes and adds label-free diagnostics that show whether a classifier can exploit recording- or participant-specific information:

- **Evaluation schemes**: random epoch split, within-recording time split (train on the first 60 % of each recording, test from 60 % + 2 s), cross-subject (participant-disjoint folds)
- **Label-free diagnostics**: time-block pseudo-labels, participant identification, accelerometer-only and EEG + accelerometer controls
- **Sensitivity analyses**: channel policy, non-overlapping windows, complete cases, fold-level summaries, five random seeds, EEGNet (raw signal)
- **External validation**: bidirectional transfer with the PhysioNet EEG Motor Movement/Imagery Dataset (EEGMMIDB)

## Installation

Python 3.11 was used.

```
pip install -r requirements.txt
```

PyTorch is needed only for `eegnet_validation.py` (see `requirements.txt`).

## Data layout

```
data/
  eye_close/  S01_EC.bdf  S02_EC.bdf ...
  eye_open/   S01_EO.bdf  ...
  hands_up/   S01_HU.bdf  ...
  eegmmidb/   S001/S001R01.edf ...   (downloaded by external_validation.py if absent)
```

Set the folders with environment variables, or edit the CONFIG block at the top of `eeg_analysis.py`:

```
set EEG_DATA_DIR=D:\path\to\data             (Windows; use export on Linux/macOS)
set EEG_OUTPUT_DIR=D:\path\to\analysis_output
set EEGMMIDB_DIR=D:\path\to\eegmmidb
```

File names must contain a participant identifier (`S01`, `S02`, ...). The reader handles the acquisition software's native .bdf files and CSV/TXT exports with one column per channel.

The cohort recordings used in the article cannot be shared publicly under the IRB-approved protocol. The pipeline runs unchanged on any dataset with one recording per participant and condition. EEGMMIDB is public: https://physionet.org/content/eegmmidb/1.0.0/

## Reproducing the article

```
python eeg_analysis.py --check                               # inventory and file checks
python eeg_analysis.py --jobs 4 --policy common              # primary analysis
python eeg_analysis.py --jobs 4 --policy exclude             # 19-channel sensitivity analysis
python eeg_analysis.py --jobs 4 --policy common --step 2     # non-overlapping windows
python external_validation.py --jobs 4 --out analysis_output/policy_common
python eegnet_validation.py                                  # --quick for a smoke test
python paired_ci.py
python check_samples.py
python fold_level.py
python seed_repeat.py
python make_figures.py
python make_figS2_arial.py
```

Results are written to `analysis_output/policy_<policy>[_step2s]/` (`summary.md`, `results.xlsx`, CSV files and `figures/`). All random seeds are fixed (0); `seed_repeat.py` repeats the key comparisons with seeds 0–4 and first verifies that the original protocol reproduces the stored results.

## Applying the audit to other data

The schemes and diagnostics need only band-power features with participant, condition and window-time labels. Warning signs that a random-split benchmark does not reflect performance for new users:

- a large gap between random-split and cross-subject accuracy;
- high accuracy for time-block pseudo-labels under random splitting;
- high participant-identification accuracy;
- above-chance random-split accuracy for a contrast expected not to differ.
